# Investigating Netflix Movies

Exploratory data analysis of 1990s movies on Netflix, from the perspective of a production company that specializes in nostalgic styles. Built with Python, pandas and matplotlib.

## Questions
- What was the most frequent movie duration in the 1990s? **94 minutes**
- How many short (under 90 minutes) action movies were released in the 1990s? **7**

## Data
`netflix_data.csv` contains Netflix titles with their type, director, cast, country, release year, duration and genre. The analysis keeps only movies released from 1990 to 1999 (183 titles).

## How to run
```
pip install pandas matplotlib
python investigating_netflix_movies.py
```
